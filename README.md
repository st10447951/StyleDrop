StyleDrop 
StyleDrop is an Android clothing and streetwear application designed to help users discover clothing, manage a shopping cart, save items to a wishlist, and manage their profile and orders. The app uses a dark interface with bright pink accents for a modern streetwear-inspired look.
Features
- User authentication: Login, register, and Google sign-in interface.
- Home / product browsing: Browse clothing products and filter by categories such as All, Outerwear, Hoodies, and Trousers.
- Product cards: View product images, names, prices, and save products to a wishlist.
- Wishlist: Save clothing items for later.
- Shopping cart: Add products to the cart, review quantities and totals, and remove items.
- Checkout: Enter delivery details, contact number, delivery date, and choose a payment method (Cash on Delivery, Fastpay Wallet, or Ozow EFT).
- Orders: View order details and order status.
- Profile: Edit profile, change password, change language, and log out.
